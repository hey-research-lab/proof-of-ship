Proof of Ship · Hey Research Lab × $WIF

Back a builder with $WIF. Pay only when they ship.

Put $WIF behind a team building on Robinhood Chain. It stays in the escrow until Hey Research Lab counts real ships for that team — releases, deployed contracts, code that changed — each with its public source. No ships by the deadline, and every backer takes their $WIF back.

1 · Back

Anyone opens a bounty for a project on HEY and funds it with $WIF. Others can add to it.

2 · Ship

The builder ships. HEY reads it from its sources and counts it by the same rule as every page on HEY.

3 · Release

When the count reaches the target, HEY signs it and the $WIF goes to the builder. A share the backer chose is burned.

The escrow has no owner and no admin key; HEY's attester can only release a bounty to the address it was opened for.
